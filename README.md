# PS3 Custom Wave Studio & PKG Prep

Prosta aplikacja okienkowa stworzona z myślą o systemie **Windows 7**, służąca do projektowania własnych efektów fal (waves) dla interfejsu XMB w konsoli PS3 z zainstalowanym **HEN / CFW**.

## Funkcje
- Wybór kolorów fal oraz tła za pomocą palety kolorów.
- Suwaki do regulacji prędkości animacji oraz amplitudy.
- Eksport ustawień do formatu JSON oraz struktury plików QRC dla PS3.

## Jak uruchomić?
1. Upewnij się, że masz zainstalowanego Pythona (wersja 3.x).
2. Pobierz plik `app.py` z repozytorium.
3. Uruchom program poleceniem w terminalu:
   ```bash
   python app.py
